# 本地知识库助手示例资料

## 项目目标
本项目通过 Python 命令行示例演示 LLM、RAG 和 MCP 的配合方式：模型理解问题并选择工具，检索模块寻找文档依据，MCP 连接独立工具服务。

## 支持的文档
知识库文档放在项目的 knowledge 文件夹中。目前支持 UTF-8 编码的 Markdown（.md）和纯文本（.txt）文件，也会读取子文件夹。添加或修改文档后，下次运行会重新读取。

## 文档切分规则
文档首先按空行切成段落。如果一个段落超过 500 个字符，就继续切成最长 500 字的片段，相邻片段重叠 80 字。每个片段保留文件名与片段编号，方便定位来源。

## 当前检索方式
默认使用向量检索：通过 embedding 模型将问题与文档片段转换为向量，计算余弦相似度，取最相近的 3 个片段交给 LLM。相似度不等于回答正确率，文档可能不足以回答问题。可以通过 --search keyword 切换到词语匹配检索，比较两者的结果。文档向量缓存在 .cache 中，文档正文、模型或服务地址变化时重新计算；问题向量每次生成。当前不使用向量数据库。

## 回答要求
助手需要根据检索到的文档回答问题，并使用 [1]、[2] 这样的编号标注依据。文档没有提供的信息，应明确说明不知道。

## MCP 工具
助手通过 MCP stdio 协议连接本地工具服务。服务提供 list_documents（列出文档）、read_document（读取文档）、search_documents（检索知识库）和 save_note（保存笔记或清单）四个工具。保存的文件位于 outputs 文件夹，不允许覆盖已有文件。只在用户明确要求保存时使用保存工具。
