# 从前端交互到本地知识库助手

这是一组从页面交互逐步走向 AI 应用的学习示例。你将依次完成计数器与任务列表、带后端接口的任务管理页面、可以调用本地工具的商店助手，以及能检索文档并标注来源的知识库助手。

每个阶段都有独立的代码和运行说明。可以按顺序学习，也可以根据已有基础选择入口。

## 从哪里开始

如果你正在学习 JavaScript，先从阶段 01 熟悉页面元素和事件；如果已经掌握 DOM 操作，可以从阶段 02 理解前后端如何通过 HTTP 交换数据。阶段 03 适合会编写 Python 函数、读写 JSON，并希望理解模型工具调用的读者；阶段 04 在此基础上引入独立工具服务和文档检索。

阶段 01、02 使用同一个任务列表主题。阶段 03、04 是独立的命令行示例，用于学习 AI 应用的调用流程，并没有接入阶段 02 的网页。

## 学习路径

| 阶段 | 目录 | 学习完成后能解释的问题 | 阅读入口 |
| --- | --- | --- | --- |
| 01 | `01fronted/` | 点击按钮后，状态如何更新到页面上？ | [前端练习说明](01fronted/README.md) |

阅读时建议遵循“运行示例 → 追踪一次交互 → 修改一个条件 → 对照结果”的顺序。各阶段说明均提供观察重点和练习建议。

## 运行准备

- 阶段 01：使用浏览器打开 HTML 文件即可。
- 阶段 02～04：建议使用 Python 3.11+，在各阶段目录中创建独立虚拟环境并安装对应依赖，具体命令见各目录说明。
- 阶段 03、04 的模型调用：复制对应的 `.env.example` 为 `.env`，填写个人 API 配置。安装依赖后，可以先运行离线测试；阶段 04 还提供不需要密钥的关键词检索和工具发现模式。
- 文档中的终端命令使用 PowerShell。macOS / Linux 中虚拟环境解释器路径为 `.venv/bin/python`。

先将终端切换到要学习的目录。例如，从仓库根目录进入阶段 03：

```powershell
Set-Location "03LLM+Tool Calling"
```

各阶段 README 中的命令都从该阶段目录执行。目录名称含空格时需要使用引号；不需要先激活虚拟环境，命令会直接使用其中的 Python 解释器。

## 几个会用到的概念

| 概念 | 在示例中的作用 |
| --- | --- |
| DOM | JavaScript 读取和修改页面元素的接口 |
| HTTP / JSON | 浏览器与后端交换请求和数据的方式 |
| LLM | 大语言模型，负责理解问题、选择工具和组织回答 |
| Tool Calling | 模型输出工具名称和参数，程序执行工具后回传结果 |
| RAG | 检索增强生成，先寻找相关文档片段，再将片段作为回答依据 |
| MCP | 模型上下文协议，本示例用它连接独立进程中的工具服务 |

## 示例范围与数据

这些项目用于学习，不包含生产环境所需的身份认证、持久化和完整权限控制。任务列表保存在内存中；商店订单、商品及规则均为虚构示例；`knowledge/` 内是公开的示例学习资料。

模型调用会消耗服务额度。阶段 04 的向量检索会将文档片段发送给 embedding 服务，回答时也可能将相关片段发送给聊天服务；添加资料前请确认可以向所配置的服务提供这些内容。

## 本地文件与公开分享

仓库只提供 `.env.example`，不包含密钥。`.gitignore` 已排除本地 `.env`、虚拟环境、编辑器配置、缓存和运行输出。运行产生的笔记保存在阶段 04 的 `outputs/`，不纳入版本控制。

新增知识库资料、测试数据或截图时，应先移除真实个人信息。使用 `git status --short --untracked-files=all` 查看待提交文件；若密钥曾被提交或公开，应在服务商控制台撤销并重新生成，删除当前文件不会清除已有的 Git 历史。
