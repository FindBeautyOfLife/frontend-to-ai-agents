# JavaScript 页面交互

使用浏览器直接打开本目录中的 HTML 文件，无需安装依赖。这两个文件均包含可运行的实现。

## 学习目标

通过两个页面，理解 JavaScript 如何保存状态、响应用户操作并更新 DOM。阅读前需要了解基本 HTML 标签，以及 JavaScript 的变量和函数。

## 运行与观察

| 文件 | 功能 | 学习重点 |
| --- | --- | --- |
| `01.计数器.html` | 加一、减一、重置 | 使用变量保存状态，通过事件监听更新 DOM |
| `02.Todo List.html` | 添加和删除任务 | 读取输入、创建元素、使用事件委托处理删除 |

先打开计数器，依次点击“加 1”“减 1”“重置”，观察显示值与变量 `count` 的关系。计数器允许负数。

再打开任务列表，添加两条任务并删除其中一条；输入只有空格时，不应新增任务。刷新页面后，计数和任务都会重置，因为状态只保存在页面内存中。

## 对照代码阅读

1. 先看 HTML 中的 `id`，再找到 `<script>` 中对应的 `getElementById()`，理解脚本如何引用页面元素。
2. 在计数器中跟踪一次点击：`addEventListener()` 接收事件，修改 `count`，再通过 `textContent` 更新显示。
3. 在任务列表中跟踪一次添加：读取输入并去除首尾空格，创建 `li` 和删除按钮，将它们加入列表，再清空输入框。
4. 找到列表上的点击监听器。点击按钮的事件会传到列表，处理函数通过 `event.target` 找到被点击的按钮，再删除它所在的任务。这种方式称为事件委托，新创建的按钮也适用。

任务文本使用 `textContent` 设置，输入中的 HTML 标签会作为普通文字显示。

## 动手练习

- 给计数器增加步长输入，确认加减按钮都使用新的步长。
- 为任务列表增加回车添加，并复用点击按钮时的添加逻辑。
- 用 `localStorage` 保存任务，观察刷新后是否能恢复列表。

完成后，可以尝试不看代码解释：为什么变量变化后还需要更新 DOM？为什么新添加的删除按钮没有单独注册监听器也能工作？
